## Kaip paskelbti per GitHub Pages

1. Sukurkite viešą (Public) repozitorijų, pvz., `atbulinis-zodynas`.
2. „Add file“ → „Upload files“ → nutempkite visus šio aplanko failus → „Commit changes“.
3. „Settings“ → „Pages“ → „Deploy from a branch“ → `main` / `(root)` → „Save“.
4. Po 1–2 min. žodynas bus adresu `https://JŪSŲ-VARDAS.github.io/atbulinis-zodynas/`.
